# Mock API Server - Backend

This directory contains the backend implementation for the Mock API Server. The backend is built using Node.js and Express.js.

## Directory Structure

- `src/`: Contains the source code for the backend.
- `tests/`: Contains unit and integration tests.
- `config/`: Contains configuration files.
- `middleware/`: Contains Express middleware.
- `services/`: Contains core business logic modules.
- `handlers/`: Contains request handlers for API endpoints.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Run tests:
   ```bash
   npm test
   ```
